二本目、「Does More Thinking Pay Off? Reasoning Cost and Correctness of LLMs in Code Generation and Bug Fixing」。著者はAndie Huang、Ying Pang、Qian Zhangほかです。多くの大規模言語モデルはコード生成やバグ修正前に、思考プロセスを明示的に出力しますが、評価基準は通常正解率のみを報告しており、その追加的な思考コストが本当に価値があるのか不明確です。本研究では、HumanEval Pro、MBPP Pro、BugsInPy から抽出した 866 の Python タスクを用いて、五つのモデル設定で検証しました。思考を有効にすると、Qwen3-32B モデルの HumanEval Pro における正解率は平均 71.1% から 76.5% に向上し、BugsInPy では 3.5% から 7.9% に改善されました。しかし MBPP Pro では 68.1% から 69.5% へのわずかな向上は統計的に有意ではなく、一つのタスクあたり平均 2000 文字以上の思考トークンを消費します。全体的に思考プロセスが長いほど必ず精度が高まるわけではありません。定性分析では、コード生成では実装を選択・確認し、バグ修正では故障箇所を特定して修復計画を立てることが多いことが分かりました。さらに、保存された思考プロセスをオフラインで半分に短縮し、思考機能を無効にしたモデルに解を生じさせる実験を行いました。前半部分のみを残しても正解率には統計的に有意な低下は見られませんでした。思考が繰り返しになるのを待って停止するルールや、コードが最初に現れた時点で停止するルールは、どちらの場合も単純な固定短縮法より優れていません。これらの結果は、思考を増やすことが常に良いわけではないことを示しており、研究では正解率だけでなく思考コストも報告すべきであることを示唆しています。

三本目、「A lightweight C Code Generator for Heterogeneous TinyML Systems」。著者はChen Liu、Bernhard Vogginger、Christian Mayrです。人工知能の進化はトレーニング框架や計算ハードウェアの発達に支えられてきましたが、エコシステムは依然として断片的です。モデル形式と専用ハードウェアが対応しきっておらず、学習から推論への転送コストを減らす必要があります。本研究では、ドメイン固有アクセラレーターを備えた裸金属の不均一システム向けに、軽量な C コード生成器を提案します。RISC-V ベースのレーダー DSP を対象としたケーススタディで、事前最適化技術を適用した結果、マイクロ TVM フローとの比較において推論速度が 2.3 倍向上し、バイナリサイズは 20 パーセント削減されました。これにより、リソース制約のあるエッジデバイスへの新たな選択肢が提供されます。コードは Gitlab で公開されています。

四本目、「HiLo-RD: Cross-Budget Self-Distillation for Masked Diffusion Language Models」。著者はXiang Li、Chengting Yu、Jungang Liほかです。この研究は、生成予算が限られた状況下で動作するマスキード拡散言語モデルの性能向上を目指すものです。従来の自動回帰モデルとは異なり、このモデルは生成すべき内容と、どこにその内容を確定させるかを同時に決定する必要があります。しかし、これにより生じる課題として、推論が完了する前に有用なコンテンツを予測し、後続の予測に影響を与える答えとなるトークンをいつ固定するかという二つの問題があります。研究チームは、予算不足によってモデルが解答の一部を早めて固定してしまう現象を発見しました。これは正しい解決策が存在しても、中間ステップを解決する前に解答フラグメントを境界付近で固定してしまい、それが後の推論を誤方向に誘導する原因となります。既存の手法では、同じモデルが大きなウィンドウで追う強力な経路を直接転移させることができませんでした。そこで提案された HiLo-RD は、大規模ウィンドウの教師状態と切り詰められた小規模ウィンドウの視点をペアにし、確定位置での隠れ表現を一致させることでこのギャップを埋めます。これにより外部教師なしにトークン予測とコミットメント順序を指導します。数学ベンチマークでは低予算精度が向上し、応答長が短縮されました。コード生成においてもドメイン特化訓練なしで同様の効果が見られました。GSM8K では精度が 9.4 ポイント上昇し、平均読了長は約 25% 短縮しました。

五本目、「CAMR: Compatibility-Aware Memory Replay for Continual Learning in Large Language Models」。著者はJingpu Yang、Tianhao Li、Fengxian Jiほかです。継続学習において、大規模言語モデルは新しい知識を獲得しながら既存の知識を保持する必要があります。しかし、どの例に監督を割り当てるか、またどの過去の例を再確認すべきかが課題です。本研究では、CAMR という適応型フレームワークを提案します。これは、現在の例への監督と歴史的事例の再生を同時に制御する仕組みです。具体的には、互換性チェックと学習されたメモリゲートを組み合わせて、三つの行動に対するオンライン政策を導きます。一つ目は一般的な再生を用いて新しい例を学習すること、二つ目は互換性のある関連事例を共同で強化すること、そして三つ目は既習と確認された重複例への直接監督をスキップすることです。この政策は、獲得、保持、およびトレーニングコストのフィードバックから学びます。評価では Qwen3-8B-Base モデルを用い、WikiBigEdit データセットで事実更新タスクを実施しました。元の一致率において、三千事実に達した時点で九三・六六パーセントとなり、十万事実に至った時点でフル履歴再生を凌駕しました。また、四つの TRACE タスクで最高スコアを獲得し、金融質問応答や数学的推論などを含む一連のタスクで初期学習以上の性能を維持または向上させました。
