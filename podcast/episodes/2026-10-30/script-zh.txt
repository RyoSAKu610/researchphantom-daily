第一篇论文：「Guided-RLVR: Guided Exploration in Reinforcement Learning with Verifiable Rewards」。作者是Bo Yang、Zishuai Zhang、Weihua Li等。强化学习结合可验证奖励方法在提升大语言模型的数学和编程推理能力方面表现显著,但近期研究发现其生成的推理路径往往局限于狭窄范围,导致探索空间不足。为此,研究人员提出了一种名为 Guided-RLVR 的新方法。该方法引入了一个轻量级控制器,利用关键步骤中的思维令牌作为结构元素,向采样分布中注入具有语义意义的引导令牌。这种策略鼓励模型从多种不同的推理视角出发解决问题,从而有效扩大了探索空间。在数学推理和代码生成基准测试上的实验表明,该方法在性能上持续优于现有的强化学习结合可验证奖励方法,并且能生成更多样化的推理路径。
术语定义和方法局限，读作者本人的表述最可靠，感兴趣的听众可以打开原文对照。
第二篇论文：「Does More Thinking Pay Off? Reasoning Cost and Correctness of LLMs in Code Generation and Bug Fixing」。作者是Andie Huang、Ying Pang、Qian Zhang等。这项研究探讨了让大语言模型在写代码前先进行推理,是否真的能提升效果。目前许多模型会输出显式的推理过程,但现有评测通常只报告最终代码是否正确,并未考虑推理消耗了多少计算资源。作者使用来自三个不同基准的八百六十六个 Python 任务,在五组模型设置下考察了开启推理带来的准确率提升与 token 开销。结果显示,在特定模型上,开启推理能将某些任务的通过率从百分之七十一点一提高到百分之七十六点五,但在另一项任务中提升并不显著,尽管单任务平均消耗超过两千个思考 token。分析表明,长推理过程不一定代表更高准确率;在代码生成中模型主要选择并检查实现方案,而在修复 bug 时则定位故障并规划修复。此外,研究还测试了截断推理过程的效果,发现仅保留推理过程的前半部分并不会显著降低正确性。这些结果说明更多的思考并不总是更好,未来的研究应同时报告推理成本与正确率。
我们刻意不在节目里给这项研究定位，作者的原文和图示说得比摘要更清楚。
第三篇论文：「A lightweight C Code Generator for Heterogeneous TinyML Systems」。作者是Chen Liu、Bernhard Vogginger、Christian Mayr。过去十年,人工智能的进步依赖于复杂的训练框架和强大的硬件,但整个生态系统依然碎片化。模型通常以特定框架的格式存在,而针对新算子的专用硬件也不断涌现。为了降低从训练到推理的转换成本,研究团队提出了一种轻量级的 C 代码生成器,专为包含领域专用加速器的无操作系统异构系统设计。通过一项基于 RISC-V 雷达数字信号处理器的综合案例研究,他们展示了该方法的效果。该加速器采用了提前优化技术,包括权重调整和偏置融合。结果显示,与使用相同加速器的微 TVM 流程相比,推理速度提升了 2.3 倍,二进制文件大小减少了 20%。这一成果为资源受限的边缘设备提供了另一种可行的选择,相关代码已在 Gitlab 开源。
这篇论文采用的新方法细节与评测是否可靠，需要到原论文中确认，本节目不做判断。
第四篇论文：「HiLo-RD: Cross-Budget Self-Distillation for Masked Diffusion Language Models」。作者是Xiang Li、Chengting Yu、Jungang Li等。这项研究针对掩码扩散语言模型在生成预算有限时遇到的困难。这类模型不仅要决定生成什么内容,还要决定在哪里停止生成。现有方法存在过早确定的问题,即模型可能在推理未完成时就固定了答案片段,从而干扰后续思考。为此,研究者提出了一种名为 HiLo-RD 的新方法,它通过将大窗口教师状态与裁剪后的小窗口视图配对,并在已确定的位置匹配隐藏表示,以此指导 token 预测和确定顺序,无需外部教师。实验显示,该方法在数学基准测试中显著提升了低预算下的准确率并缩短了回答长度。具体而言,在 GSM8K 数据集上,准确率提高了 9.4 个百分点,平均可读长度减少了约 25%,且这些增益也延伸到了代码生成任务中。
仅凭摘要无法判断结果有多强，评测的前提和实验范围请看正文与图表。
第五篇论文：「CAMR: Compatibility-Aware Memory Replay for Continual Learning in Large Language Models」。作者是Jingpu Yang、Tianhao Li、Fengxian Ji等。持续学习要求大语言模型在获取新知识的同时保留旧知识,但决定哪些新示例需要监督以及复习哪些历史示例仍具挑战。本研究提出了一种名为兼容性感知记忆回放的方法,这是一个自适应框架,联合控制当前示例的监督与历史数据回放。该方法结合兼容性检查与学习到的记忆门控机制,引导在线策略执行三项操作:对 incoming 示例进行通用回放、联合强化兼容的相关示例,以及跳过已掌握重复示例的直接监督。策略在获取、保留和训练成本反馈下学习,并受限于每次到达时的有界回放预算。研究使用 Qwen3-8B-Base 模型在事实更新及跨任务跨领域学习中进行了评估。结果显示,该方法在 WikiBigEdit 数据集上,从三千到十万个事实均优于其他方法,并在三千个事实时达到百分之九十三点六六的匹配率;此外,它在所有选定的 TRACE 任务中取得了最高最终分数,并在涵盖金融问答、数学推理、代码生成和摘要的任务序列中保持或提升了早期任务的性能。
