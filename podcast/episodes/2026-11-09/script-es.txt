El primer artículo: «Denoising Diffusion Probabilistic Models». Los autores son Jonathan Ho, Ajay Jain, Pieter Abbeel. Esta investigación se centra en el estudio de los modelos de difusión probabilística, una aproximación que busca entender cómo se puede generar imágenes complejas a partir de ruido aleatorio. El problema fundamental que aborda este trabajo es la dificultad de crear datos sintéticos realistas y de alta calidad, especialmente cuando no se tienen etiquetas o categorías predefinidas para guiar el proceso, lo que se conoce como generación condicional o sin condiciones. Para resolver esto, los autores proponen un enfoque basado en aprender a invertir un proceso específico. Imaginen que tenemos una imagen clara y, paso a paso, vamos añadiendo ruido hasta que la imagen se vuelve completamente indistinguible de estática o ruido blanco. Este es el proceso de agregar ruido. Lo interesante de este modelo es que no solo estudia ese camino hacia el caos, sino que aprende a hacer lo contrario: el proceso inverso de quitar el ruido. Al aprender esta secuencia inversa, el modelo puede tomar un conjunto inicial de ruido y, mediante una serie de pasos calculados, eliminar gradualmente esa interferencia para revelar una imagen coherente y estructurada. Este método se denomina modelo de difusión probabilística porque utiliza las reglas matemáticas de la probabilidad para describir cómo cambia la distribución de los datos a medida que se añade o se elimina ruido en cada etapa del proceso. La propuesta técnica que presentan los autores gira en torno a cómo se entrena este sistema para realizar esa eliminación de ruido de manera efectiva. El núcleo del método se basa en enseñarle al modelo a predecir el ruido que ha sido añadido en cada paso específico del proceso inverso. En lugar de intentar reconstruir la imagen completa desde cero en un solo paso, lo cual es extremadamente difícil y propenso a errores, el sistema aprende a identificar qué nivel de ruido está presente y cuánto debe removerse para avanzar al siguiente estado más limpio. Esta estrategia de aprendizaje mediante predicción de ruido se conecta directamente con otra técnica importante en estadística y aprendizaje automático conocida como coincidir puntuaciones o score matching. El trabajo demuestra y establece formalmente la relación matemática entre usar el ruido para guiar el aprendizaje y el concepto de coincidencia de puntuaciones, mostrando que son enfoques complementarios que pueden utilizarse para lograr los mismos objetivos finales de modelado de datos. Al vincular estas dos ideas, los autores proporcionan una base teórica sólida que explica por qué predecir el ruido funciona tan bien para generar muestras realistas, ofreciendo claridad sobre los fundamentos subyacentes del método propuesto. Una vez definido el modelo y el proceso de entrenamiento, se pone a prueba su rendimiento en tareas concretas para verificar su utilidad práctica. Los autores reportan los resultados obtenidos al aplicar estos modelos de difusión probabilística en la generación de imágenes sin condiciones, lo que significa que no hay ninguna instrucción previa sobre qué tipo de imagen debe ser generada; el modelo simplemente crea imágenes basándose únicamente en la distribución general de datos que ha aprendido durante su entrenamiento. Para validar la calidad de las imágenes producidas por este nuevo enfoque, se utilizaron dos conjuntos de datos estándar y ampliamente reconocidos en la comunidad de investigación: CIFAR-10 y LSUN. El conjunto CIFAR-10 contiene imágenes pequeñas de objetos cotidianos como vehículos, animales y paisajes, mientras que LSUN incluye imágenes mucho más grandes y detalladas de escenas naturales y habitaciones interiores. Al generar muestras a partir de estos datos sin usar etiquetas específicas para cada imagen individual, el sistema demuestra su capacidad para crear variaciones diversas y creíbles dentro de las categorías aprendidas. Los hallazgos presentados en este estudio indican que los modelos entrenados con esta metodología logran una calidad de muestra muy alta. Al comparar visualmente y cuantitativamente las imágenes generadas con las originales, se observa que la apariencia realista es notable. Esto significa que las texturas, los bordes y las estructuras de las imágenes creadas por el modelo son difíciles de distinguir de fotografías o dibujos hechos a mano por humanos. La propuesta no solo funciona en teoría, sino que entrega resultados tangibles donde las imágenes generadas poseen una coherencia interna y un nivel de detalle que supera lo esperado para ese tipo de aproximaciones probabilísticas. Al reportar estos éxitos en la generación de imágenes para ambos conjuntos de datos, el trabajo confirma que aprender a invertir el proceso de adición de ruido es una vía prometedora y efectiva para abordar el problema de la síntesis de imágenes. La explicación del mecanismo detrás de esto, junto con las pruebas empíricas en CIFAR-10 y LSUN, ofrece una visión clara de cómo los modelos de difusión probabilística pueden convertirse en herramientas poderosas para crear contenido visual nuevo a partir de ruido puro, estableciendo un precedente importante en el campo del aprendizaje automático generativo.
