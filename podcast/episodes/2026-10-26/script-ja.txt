Predicting the Necessity of Additional Fuzzing for Continuous Fuzzing」。著者はRiku Kato、Tatsuya Shirai、Olivier Nourryほかです。Continuous fuzzing is used for vulnerability detection in Open Source Software (OSS). Large-scale services such as Google's OSS-Fuzz fuzz over 1,300 projects and have revealed more than 10,000 vulnerabilities. Despite this, a considerable time lag often exists between when a vulnerability is introduced and when it is detected (i.e., the window of exposure). Given the computational cost of additional fuzzing, we aim to allocate fuzzing resources efficiently using vulnerability-risk estimates.

To study ELK empirically, we need model organisms that mirror this setting. Existing model organisms fall short in several respects.

三本目、「How Effectively Do Security Skills Guide Coding Agents in Vulnerability Detection in Linux Kernel?」。著者はHaoran Xue、Nikta Akbarpour、Gias Uddinほかです。Large language model (LLM) coding agents, such as Claude Code, are increasingly used for security auditing, with task-specific skills providing reusable vulnerability-analysis procedures. We conduct the first large-scale empirical study of 37 security skills using Claude Code with four underlying LLMs on 100 real Linux kernel vulnerabilities across ten classes, totaling 14800 runs.
