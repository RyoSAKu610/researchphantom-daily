Первая статья: «Raise or Check? Predicting the Necessity of Additional Fuzzing for Continuous Fuzzing». Авторы: Riku Kato, Tatsuya Shirai, Olivier Nourry и др. Continuous fuzzing is used for vulnerability detection in Open Source Software (OSS). Large-scale services such as Google's OSS-Fuzz fuzz over 1,300 projects and have revealed more than 10,000 vulnerabilities. Despite this, a considerable time lag often exists between when a vulnerability is introduced and when it is detected (i.e., the window of exposure). Given the computational cost of additional fuzzing, we aim to allocate fuzzing resources efficiently using vulnerability-risk estimates.

Вторая статья: «Towards Robust Model Organisms for Eliciting Latent Knowledge». Авторы: Lennart Finke, Hardik Bhatnagar, Euodia Dodd и др. A key problem in AI safety is eliciting latent knowledge (ELK), extracting information from a model that is misaligned and more knowledgeable than its overseer. For example, a misaligned model used to scan code for vulnerabilities may want to withhold its findings, i.e., sandbag, in order to exploit them later. To study ELK empirically, we need model organisms that mirror this setting. Existing model organisms fall short in several respects. In this work, we train model organisms to withhold solutions in a vulnerability detection task.

Четвёртая статья: «The One-Pixel of Reasoning: One Truthful Relation Is Enough to Mislead LLM Agents». Авторы: Jinwei Hu, Youcheng Sun, Yi Dong и др. Can one sentence manipulate an agent's belief by targeting a single implicit warrant linking evidence to a conclusion? In this paper, we introduce the one-relation attack (ORA), a novel cognitive attack on this inferential relation. ORA localizes a critical implicit warrant and performs a one-relation intervention using a single source-grounded sentence that qualifies this warrant and steers the agent toward an incorrect belief.

Пятая статья: «Beyond Confidence: Rethinking Uncertainty Calibration in Deep Code Models». Авторы: Ravishka Rathnasuriya, Wei Yang. Deep learning models have shown significant promise in code-related tasks. While confidence calibration techniques have been proposed to improve model reliability, their effectiveness in real-world tasks with strict accuracy requirements remains uncertain. In this paper, we investigate two key questions: first, whether existing measurement metrics, including confidence scores and uncertainty metrics, are effective for guiding selective prediction; and second, whether existing calibration techniques can improve these metrics to better identify cases where model predictions are likely to succeed or fail.

Седьмая статья: «SecReason: Vulnerability Detection and In-Stream Self-Repair for LLM Code Generation». Авторы: Ruidong Han, Zhensu Sun, Chengyan Ma и др. Large language models (LLMs) may introduce security vulnerabilities into generated code, which can persist into production when verification focuses on functional correctness. Existing defenses act before, during, or after generation, but none inspects the code during generation. Security prompts and retrieved security knowledge act before any code exists, constrained decoding limits token choices but cannot guide repair, and post-hoc repair must regenerate the full response.
