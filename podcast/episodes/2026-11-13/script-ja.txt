一本目、「Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via On-Policy Distillation」。著者はLirui Luo、Kelong Mao、Xinwei Yangほかです。長期的なタスクを処理する言語モデルエージェントは、コンテキストを超える履歴の中から何を書き込み、何を参照すべきかを決定する必要があります。従来のオンポリシー蒸留法では、事前学習に含まれないメモリツールを使用するため、教師モデルが適切な指導を与えられず、学生モデルも意味のある行動を十分にサンプリングできません。本研究では、その課題を解決するために、ショップやコーディングなど 5 つの環境からなる CAMG-II を構築し、政策にファイル作成や検索などの Bash アクセスと永続的な作業空間を提供しました。さらに、CAMG-II を用いて CAMP-II という手法を開発し、事前学習済みの教師モデルから直接ファイルベースのメモリ行動を学習させました。その結果、CAMG-II において CAMP-II は最も強い蒸留基盤の 2.97 倍の性能向上を達成しました。また、この学習したメモリ行動は Terminal-Bench 2.1 や SWE-Bench Pro V2 という外部ベンチマークでも成功率が向上し、汎用性を示しています。

二本目、「Synapse-Control: Making Agent Experience Actionable with Lightweight Runtime Control」。著者はZhiyuan Huang、Shengan Zheng、Chenghu Yangほかです。複雑なツールを使うタスクで失敗した経験を再利用して信頼性を高めるのは、大規模言語モデルエージェントの重要な課題です。しかし、既存のシステムは失敗の原因を診断するために毎回大規模モデルを呼び出し、コストがかかります。本研究では、軽量な制御平面を持つエージェントランタイム「Synapse-Control」を発表しました。このシステムは、まずルールで関連する助言を絞り込み、次に教師データで学習させた 17 億パラメータの分類器が候補をスコアリングします。これにより失敗診断のための生成コストを抑えます。また、必要な引数などのチェック条件をマイクロコントラクトとして記述し、過去のガイダンスやフィードバックを記録して重複した提案を防ぐ仕組みも持っています。AppWorld と WebShop で 1,308 回の試行を行い、ベースラインより成功率を 29.8% 向上させました。さらに生成診断の呼び出し回数を 4,987 回削減し、補助制御時間をそれぞれ約半分まで短縮したことを報告しています。
