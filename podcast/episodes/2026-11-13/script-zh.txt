第一篇论文：「Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via On-Policy Distillation」。作者是Lirui Luo、Kelong Mao、Xinwei Yang等。随着大模型代理处理长周期任务时,交互历史往往超出其上下文限制,它们必须决定何时记录或读取信息。现有方法依赖模型训练之外的工具进行策略蒸馏,但这导致教师无法指导未使用过的接口,学生也难以采样到有效的记忆动作。针对这一问题,研究团队构建了 CAMG-II 环境套件,涵盖购物、编程等多个领域,提供 Bash 访问和持久化工作区,使代理能将文件操作作为跨上下文替换的记忆手段。在此基础上,他们提出了 CAMP-II 方法,利用异步同策略蒸馏,从拥有文件操作先验的冻结教师模型中学习文件记忆行为。实验显示,该方法在同环境下获得的增益是现有最强基准的 2.97 倍,且在外部基准测试中也取得了更高的成功率。

第二篇论文：「Synapse-Control: Making Agent Experience Actionable with Lightweight Runtime Control」。作者是Zhiyuan Huang、Shengan Zheng、Chenghu Yang等。大型语言模型智能体通常复用执行经验来提升复杂工具任务的可靠性,但像 Sentry 这样的系统需要调用大模型生成故障诊断才能获取建议,这增加了推理成本。本研究提出了 Synapse-Control,这是一个轻量级的智能体运行时控制平面。它通过规则筛选相关建议,并利用一个基于教师标注数据微调的 17 亿参数分类器对候选建议进行评分,从而替代了生成式诊断。系统使用微契约编码可复用的接口检查,如必要参数和有效选项,而不规定完整的任务程序。此外,一个提示值表记录了早期的指导和反馈,通过冷却期和令牌预算检查来限制重复建议。在 AppWorld 和 WebShop 两个基准上,该方法进行了 1308 次尝试,实现了 270 次成功,比基线方法高出 29.8%。实验还显示,该系统替换了 4987 次生成式诊断调用,并将辅助控制时间分别减少了 50.2% 和 51.0%。
术语定义和方法局限，读作者本人的表述最可靠，感兴趣的听众可以打开原文对照。
第三篇论文：「Stinging the Swarm: Extracting Attacker Intelligence from a Twin-Controller OT Honeypot」。作者是Canyon Grey Dell'Omo、Joao Pedro de Carvalho Voltani。自动语言模型代理能像蜂群一样快速攻击工业控制器。这项研究提出了一种名为 Talos 的实时网关,它能在毫秒内判断每个请求是否有害。恶意代理会被路由到一个与真实工厂完全镜像的诱饵设备中,在那里继续攻击但不会造成实际损害。研究人员用两千四百个自主攻击者测试了该流程,包括那些试图隐藏身份的复杂策略。结果显示,没有任何写入操作到达真实工厂,因为网关切断了伤害路径,且未映射的寄存器被直接拒绝。此外,系统还能通过分析攻击行为,从沉默或伪装的攻击者身上提取出高置信度的身份画像,从而获取有价值的情报。

第四篇论文：「Agent-Guided Discovery of Exchange-Correlation Functionals with Physics-based Validation」。作者是Achuth Chandrasekhar、Amir Barati Farimani。精确且紧凑的交换关联泛函是预测密度泛函理论的核心。尽管符号搜索和语言模型智能体可以提出新的函数形式,但尚不清楚这些新项是否具有物理意义,以及它们能否通过自洽性和外部评估。本研究将前沿大语言模型智能体与 GPU 评估器连接,利用仅训练拟合、持久记忆及自洽外部评估方法。Opus-5.5 智能体在筛选阶段使用的令牌数比 Codex 少约四十倍,并发现了一个候选泛函 O159。该泛函通过平滑密度窗口放大同自旋相关项。经重新拟合后,它在近等轨道区域主要降低反应能误差,并使重原子总能量误差降低百分之二十九。相比之下,进化搜索未超越其种子模型。自洽的 O159 将 B97M-V 在测试集上的误差降低了百分之十一点七,其平均归一化误差比优于 GAS22 并接近 B97M-V。这表明大语言模型智能体产生的紧凑泛函改进通过了基于物理的自洽验证。
这篇论文采用的新方法细节与评测是否可靠，需要到原论文中确认，本节目不做判断。
